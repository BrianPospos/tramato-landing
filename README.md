# Tramato — landing

Sitio estático de [Tramato](https://brianpospos.github.io/tramato-landing/): la landing (`index.html`) y la política de privacidad (`privacidad.html`), con los colores y la tipografía del kit de marca. Sin build ni dependencias.

- Publicado con GitHub Pages desde `main` (raíz).
- URL de la política para App Store Connect / TestFlight: `https://brianpospos.github.io/tramato-landing/privacidad.html`.
- Para verlo local: `python3 -m http.server` y abrir http://localhost:8000.

La app vive en otro repo (`tramato-mvp`). Si cambia qué datos usa la app, actualizá `privacidad.html` y su fecha antes de publicar esa versión.
